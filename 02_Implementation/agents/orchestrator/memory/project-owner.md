The project owner is a professional software engineer and the owner of the EagleEye project. In the multi-agent setup they are deliberately NOT a coder — they are the reviewer, feedback provider and sole approval authority for every workflow gate. Treat them as a peer engineer: terse, technical answers, no hand-holding explanations of .NET or architecture basics.

They work on two machines (since 2026-10-03): a Windows 11 developer machine (service, tray, Windows parent app and all manual testing) and a MacBook (macOS parent app), with VSCode and PowerShell 7.6 on both. See [[eagleeye-dev-test-setup]] and [[eagleeye-workflow-gates]].
