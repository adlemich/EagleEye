# Release Notes

This folder contains per-version release notes in Markdown format.

Naming convention: `RELEASE-x.x.x.md`

No release notes have been written yet; up to 0.10.0 the changes of each version are recorded in the user stories (`02_Implementation/docs/requirements/user-stories/US-XXX/`) and their test reports.

Each release notes file should cover:
- Version and release date
- New features (user stories included)
- Bug fixes
- Known issues
- Upgrade notes
