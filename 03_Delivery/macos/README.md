# Delivery — macOS

This folder contains the macOS release artifact: the `.dmg` disk image of the Mac parent app (ad-hoc signed, not notarised, ADR-019/ADR-020).

Generated by: `02_Implementation/scripts/package-macos.ps1`
Format: `EagleEye-ParentApp-x.x.x.dmg`

## Installing or updating the Mac app

Allow the first start once in *System Settings → Privacy & Security → Open Anyway* (ADR-019).

**If the app does not connect after an update:** After installing a rebuilt `.dmg`, the app may not connect: macOS treats every ad-hoc signed build as a new app. *System Settings → Datenschutz & Sicherheit → Lokales Netzwerk* then lists one EagleEye entry per build; all show as on, but the current build is not allowed. Fix: quit the app (Cmd+Q), switch the EagleEye entries off and on again, start the app, and answer the Keychain prompt with "Immer erlauben". A failed ping to the service PC proves nothing (Windows blocks ICMP by default); test TCP port 5443 instead: `nc -z -G 3 <service-pc> 5443`.

Contents are gitignored (binary release files). This folder is a deployment target only.
